# Third-Party Vendor Risk Assessment

## Overview

This project is a simulated Third-Party Risk Management (TPRM) assessment
of CloudLedger Technologies Ltd., a fictional SaaS vendor being evaluated
by Meridian Trust Bank plc.

The assessment evaluates the vendor's security, operational resilience,
data protection, compliance, fourth-party risk, and overall residual risk.

## Project Objective

The objective of this assessment is to determine whether the vendor's
risk profile is acceptable under the bank's third-party risk requirements
and to provide a risk-based recommendation.

The assessment follows the TPRM lifecycle:

**Scope → Tier → Assess → Rate → Report → Monitor**

## Project Structure

### Pre-Project

Contains the original assessment materials provided for the exercise.

### Post-Project

Contains the completed vendor assessment, findings, risk analysis,
evidence review, and final recommendation.

## Assessment Areas

- Vendor profiling
- Inherent risk tiering
- Security control assessment
- Evidence validation
- Findings identification
- Likelihood and impact scoring
- Residual risk assessment
- Risk appetite evaluation
- Remediation planning
- Vendor decision

## Disclaimer

This is a fictional training and portfolio project.
Meridian Trust Bank plc and CloudLedger Technologies Ltd. are fictional
entities. The scenario was provided through MyFirstHack Mentorship training.
